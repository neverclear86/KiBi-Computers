# 0106: man コマンドと man ページ

- 状態: 採用
- Issue: #106（task）。前提: ADR 0098（標準 OS のビルド）、0103（コマンドの共通の約束）、0105（nano。TTY の raw とページの描き直し）、0087（復元の描き直し）、0100（init と `/etc/inittab`）
- 関連: #215（多言語の Epic。ほかの言語はコミュニティに任せる）、#21・#220（外部サイト。Markdown で書く）、#107（インストーラ）、#94（Lua の API のドキュメント）
- 番号は Issue 番号にそろえている

## 決めたこと（要約）

- `/bin/man`（`os/bin/man.zig`、部品は `os/bin/man/`）と、`/bin`・`/sbin` の全プログラムと `inittab(5)`・`intro(7)`・`kibi(7)` の英語・日本語のページを入れた
- ページの書式は **Markdown の小さなサブセット**（下）。roff は使わない（解析が小さく済み、外部サイト #21 の Markdown に流用しやすい）
- 置き場所は man-db と同じ形: `os/man/[言語/]man<節>/<名前>.<節>` → イメージの `/usr/share/man/...`（英語は言語のディレクトリなし）。
  言語を足すのはディレクトリを足すだけ（`ja`・`en` の決め打ちはない。#215 の「ほかの言語はコミュニティ」）
- 言語は OS の設定 = 環境変数（`-L` > `LC_ALL` > `LC_MESSAGES` > `LANG`）で切り替える。**クライアントの言語に合わせる部分は、この Issue では作らない**（下の「分けたこと」）
- 折り返しはビルド時ではなく、実行時に画面の幅で行う（ティア 1 の 50 桁でもティア 3 の 160 桁でも崩れない）
- 新しいシステムコール・保存形式・公開 API は足していない。man 自身のメッセージは英語の固定文（ADR 0100・0103 と同じ。訳すのはページの中身だけ）

## コマンド

```
man [-L 言語] [節] 名前...
man -k 語...
```

- 節を書かなければ 1 → 8 → 5 → 7 の順。節の名前は数字で始まる英数字（`1`・`3p`）で、オペランドが 2 つ以上のときだけ節と見る
- 探す順は「節 → 言語 → `MANPATH` のディレクトリ」。言語が後なので、`man kill` は日本語の kill(1) がなくても、ほかの節の日本語より先に英語の kill(1) を出す
- `MANPATH`（`:` 区切り、既定 `/usr/share/man`）。#112 のパッケージや HDD に置いたページも読めるように
- 名前・言語に `/` があるもの・`.` で始まるもの・制御文字を含むものは、パスの部品にしない（`man ../../etc/x` を読ませない。`LANG` は利用者が自由に書ける値なので、言語も同じに扱う）
- 見つからなければ `man: no manual entry for 名前[ in section 節]` で 1。使い方の誤りは 2。オプションは短いものだけ（ADR 0103）
- 1 ページは 64 KiB まで、続けて見せるページの合計は 128 KiB・16 ページまで（静的な領域。触るまで RAM に数えない）
- 組んだ行は 256 KiB・16,384 行まで。超えたら `page too long; output truncated` を知らせて、そこまでを見せる
- `-k`: 各ページの NAME の節（最初の `##` の節の最初の行）を、大小を区別せず部分一致で探す。`名前(節) - 説明` を名前の順に書く。
  言語の順に探し、先の言語で合ったページ（`名前.節`）は後の言語で飛ばす。先の言語で合わなければ後の言語（英語）のページでも探す
  （日本語の環境でも `man -k directory` が使える）。何もなければ `man: 語: nothing appropriate` で 1。索引は作らず、呼ばれたときにディレクトリを走査するだけ

### 言語

- 値は `-L`、なければ `LC_ALL`・`LC_MESSAGES`・`LANG` のうち最初の空でないもの
- `ja_JP.UTF-8@x` なら `ja_JP.UTF-8@x` → `ja_JP`（文字コード・修飾を除く）→ `ja`（地域を除く）→ 英語の順に探す
- `C`・`POSIX`・`C.*`・空・未設定は英語。その言語のページがなければ英語にフォールバックする（訳が一部だけでも使える）
- 既定の `/etc/inittab` には `LANG` を書かない（英語）。`env LANG=ja_JP.UTF-8` の例を inittab のコメントと `inittab(5)` に書いた。
  根は読み取り専用の同梱イメージなので（ADR 0461）、#107 のインストールまでは `export LANG=ja` か `man -L ja` で使う

### 出力

- 幅は `MANWIDTH`（20〜1024）、なければ標準出力が TTY なら画面の幅、そうでなければ 80
- 標準出力が TTY なら、太字とコードを SGR 1（太字。端末では明るい色。docs/terminal.md）で書く。TTY でなければ SGR を書かない（`man ls | grep x`）。
  属性がなくても読めるように、見出しは行の頭、本文は字下げで区別する（単色のティアもあるため）
- 標準入力と標準出力がどちらも TTY で、行が画面の行数 − 1 より多いときだけページ送りする。ほかは全部を書いて終わる（読み手が閉じたパイプでは黙って終わる。ADR 0103）

### ページ送り（`os/bin/man/pager.zig`）

- 代替画面（`CSI ? 1049 h`）に入り、右端の折り返しを切る（`CSI ? 7 l`。1 行が画面の 1 行になる）。閉じたら代替画面から出て、元の画面に戻る
- TTY は nano と同じく raw（出力の LF → CR LF だけ）にし、終わったら元のモードに戻す。シグナルも切るので、Ctrl+C・`q` を自分で終わりとして扱う
  （シグナルで殺されて raw のまま残らない。スクリプトから呼んでも端末が戻る）
- 最後の行に反転で `--More--(nn%)`、最後の画面では `(END)`
- キー: 空白・`f`・PgDn・^F・^V 次の画面（最後の画面なら閉じる。`more` と同じ）、Enter・`j`・`e`・↓・^N・^E 1 行下、`k`・`y`・↑・^P・^Y 1 行上、
  `b`・PgUp・^B 前の画面、`d`・^D / `u`・^U 半画面、`g`・`<`・Home / `G`・`>`・End 頭 / 終わり、`q`・`Q`・^C 閉じる。入力の終わりでも閉じる
- 待つのは標準入力の読み込みか、標準入力と「保存から戻った」のキューの `poll_oneoff`（#87）だけ（時計で起きない。busy loop・`yield` の連打はしない）。
  戻ったら、代替画面に入り直して描き直す（ADR 0087。nano と同じ）。そのため `cabi_realloc` を export する（`osReallocPrograms` に `man` を足した）
- キーを受けるたびに `tty.getSize` を読み直し、幅が変わったら組み直す（いちばん上の行は全体の中の割合を保つ）。行数だけなら送る量を変える

## ページの書式

UTF-8 のテキスト。1 行ずつ見る。

| 書き方 | 意味 |
| --- | --- |
| `# 名前(節)` | 題（太字） |
| `## 見出し` | 節の見出し（太字、行の頭）。以後の本文は字下げする（幅 40 以上で 4 桁、未満で 2 桁） |
| `### 見出し` | 小見出し（太字、字下げの半分） |
| 空行 | 段落・箇条書き・コードの終わり |
| 段落 | 続く行は 1 つの段落としてつなぐ（つなぎ目は空白 1 つ。どちらかが全角の文字なら空白を入れない） |
| `- ` か `* `（行の頭から 2 桁未満） | 箇条書きの 1 項目。`- ` を付け、2 行目からはその分だけ字下げする。続く行（空行まで）は同じ項目につなぐ |
| 4 桁以上の字下げ（段落の外） | コードの行（折らない。字下げの 4 桁を除いて書く） |
| ```` ``` ```` で囲んだ行 | コードの行 |
| `**太字**` | 太字 |
| `` `コード` `` | コード（太字で書き、`` ` `` は書かない。中の `**` は文字のまま） |
| `\` + 記号 | 記号をそのまま（`` \` \* \\ \# \- `` など） |

- NAME の節: 最初の `##` の節の最初の行を `名前 - 説明` の形で書く（`-k` が読む）。見出しは訳してよい（日本語のページは `名前`・`書式`・`説明`・`オプション`・`終了ステータス`・`例`・`関連項目` など）
- 節の割り当て: 1 `/bin` のコマンド、5 ファイルの形式（`inittab`）、7 概要（`intro`・`kibi`）、8 `/sbin`（`init`）
- シェルの組み込み（`cd`・`export` など）は外のコマンドではないので、`sh(1)` に一覧を書く
- Lua の API のページ（#94）も、この置き場所と書式で足す（`man<節>` の節は #94 で決める）

### 折り返し（`os/bin/man/render.zig`）

- 文字の幅は `kibi.text.width`（core の `CharWidth` と同じ表。全角は 2、結合文字は 0）。不正な UTF-8 は U+FFFD、制御文字は `?` にする
- 折れる位置: 空白（落とす）と、全角の文字の前後（日本語には空白がないため）。幅 0 の文字の前では折らない
- 行頭禁則・行末禁則は簡単な規則だけ: 句読点・閉じ括弧・長音・小書きの仮名・`!?` などの前では折らない、開き括弧の後では折らない。
  ほかに折れる位置がなければ、文字の境目で切る（UTF-8 の途中では切らない）
- 1 行の幅は必ず幅以下にする（右端までちょうど書いても空行にならない。docs/terminal.md）
- 見出しも、幅を超えたら段落と同じ規則で折る（太字のまま）
- 1 つの段落が 16 Ki 文字を超えたら、最後の空白までをいったん書き、残りを同じ段落の続きとして書く（文字を捨てない）
- コードの行は折らないが、幅を超える分だけ文字の境目で切って次の行に送る（どの幅でも行の数が決まり、ページ送りの行と画面の行が一致するように）。タブは 4 桁ごと
- SGR は行ごとに閉じる（ページ送りで行だけを描いても属性が残らない）
- 隣り合う塊の間には空行を 1 つ入れる。ただし見出しの直後と、続く箇条書きの項目の間には入れない

## 分けたこと

- **クライアントの言語に合わせる**: サーバーで動くコンピューターの OS にクライアントの言語を渡すには、init に環境変数を渡す（ADR 0049 の「環境変数なし」の約束を変える）か、
  新しいシステムコールが要り、さらに「複数のプレイヤーが同じ画面を見るとき誰の言語か」を決める必要がある（システムコールの ABI に当たるので、人の判断が要る）。
  Issue の本文では括弧書きの代わりの手段なので、この Issue は OS の設定（`LANG`）で完結させ、#661（#215 のサブ Issue）に分けた
- **外部サイトとの内容の共有**: 書式は Markdown にしたが、`website/`（#220）への結線は #220 で行う
- `more`・`less` を別のコマンドにすること（必要になったら別の Issue）

## 確かめ方

`core` の `ManCommandTest`:

- `/bin`・`/sbin` の全プログラムに英語と `ja` のページがあり、言語ごとのページの組がそろっている（コマンドを足してページを書き忘れると落ちる）
- `LANG` の形（`ja_JP.UTF-8`・`ja`・`C`・`LC_ALL`・`LC_MESSAGES`・`-L`）とフォールバック、訳のない言語、`MANPATH`
- 節の指定と探す順、見つからない（1）、使い方の誤り（2）、`../`・`.` で始まる名前・言語を断る
- `-k`（英語・日本語、日本語の環境で英語のページに合うもの、何もないとき）
- パイプの出力に ESC がない。全ページを幅 50・80、英語・日本語で組み、どの行も幅を超えない
- ページ送り: 50 桁 × 16 行の TTY で、空白・`b`・`j`・`G`・`q`・Ctrl+C、最後の画面の空白で閉じる、画面に収まるページは送らない、閉じた後に TTY のモードと元の画面に戻る

`StandardOsRestoreTest` は `cabi_realloc` を export するプログラムの集合に `/bin/man` を足した。

## 大きさ

- `/bin/man` は 24,765 バイト。ページは 46 個 × 2 言語 = 92 ファイル、合わせて 50,473 バイト（1 ページ 200〜2,000 バイトほど）
- イメージは展開後 727,838 → 803,076 バイト、項目 48 → 153（ディレクトリ 11 を含む）、`os.zip` は約 322,200 → 379,639 バイト
- いちばん小さい HDD（1 MiB・1,024 項目。ADR 0124）に #107 で写すと、容量と項目を目に見えて食う。man は `/usr/share/man` に、言語は
  その下のディレクトリにまとめてあるので、#107 で「man を省く」「英語だけ」を選べるようにできる
- サーバー側のイメージは `ImageFileSystem.bundled` が 1 つだけ持つ（全台で共有）ので、台数に比例するコストは増えない。man は呼ばれたときだけ動き、tick ごとの負荷を足さない
