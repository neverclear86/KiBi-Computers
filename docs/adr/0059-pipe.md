# 0059: パイプ

- 状態: 採用
- Issue: #59（task）。前提: ADR 0058（fd 表と標準入出力）、0072（p1 の `poll_oneoff`）
- 後続: #75（`kibi:*` でプログラムに出す口）、#101（シェルの `|`）、#81・#82（保存）、#251（仮の値の確定）
- 番号は Issue 番号にそろえている

## 決めたこと（要約）

- カーネルの中だけの仕組み。コードは `core.kernel.io`（`PipeEnd`・`Pipes`）と `FdTable.pipe`。どれも `internal`。公開 API・ABI・保存のバイト形式は足さない
- **パイプは3つのオブジェクト**: 中身の `ByteStream` と、読む端・書く端の `PipeEnd`。fd は端を指す
- 片端の最後の参照が閉じたら、中身のその側を閉じる（書く端 → 読む側は残りを読んだ後に `Eof`、読む端 → 書く側は `PIPE`）
- 待ちの key は中身の `ByteStream` の ID（`ByteStream` が自分の ID で知らせるため）
- バッファの既定の大きさは 4 KiB（`Pipes.DEFAULT_CAPACITY`。仮の値。確定は #251）

## 端を別のオブジェクトにした理由

fd が `ByteStream` を直接指すと、読む fd と書く fd が同じオブジェクトの参照になり、書く fd をすべて閉じても参照が残るので、読む側が `Eof` にならない。端を別のオブジェクトにすれば、オブジェクト表の参照カウントがそのまま「その端を持つ fd の数」になり、`dup`・子への引き継ぎ・プロセスの終わり（ADR 0058 の「すべての fd を閉じる」）が、どれも追加の処理なしで正しく働く。

- そのために `KernelObject.releaseReferences(objects, sink)` を足した。参照カウントが 0 になって表から外れた後に呼ばれ、ほかのオブジェクトの参照を返す。`PipeEnd` はここで中身の側を閉じて参照を返す
- 中身は両端が1つずつ参照を持つ。両端が閉じたら中身も表から消える
- 端の状態は中身の ID と向きだけ（書き出せる値）

## 作成（`FdTable.pipe(capacity)`）

- 読む端を `READ`、書く端を `WRITE` の権利で、小さい空き番号から順に入れて `PipeFds(read, write)` を返す
- 空き番号が2つなければ、何も作らずに `MFILE`
- オブジェクトだけ欲しいとき（fd に入れずに子へ渡すなど）は `Pipes.create(objects, capacity)`。両端の参照は呼び出し側が持つ
- 子の標準入出力へは、ADR 0058 の `StdioSource.ParentFd`・`Object` でつなぐ

## 読み書きと待ち（`FdIo`）

- `PipeEnd` は中身の `ByteStream` として読み書き・判定する（ADR 0058・0072 の `ByteStream` の振る舞いのまま）
  - 書きは空きの分だけ（一部だけ書けることがある）。空きがなければ `WouldBlock((中身, WRITABLE))`
  - 読みは空なら `WouldBlock((中身, READABLE))`。書く端が閉じていて空なら `Eof`
  - `poll`: 相手の端が閉じていれば `hangup`
- **向きの違う端（読む端への書き込み、書く端からの読み）は、fd の権利があっても `BADF`**（権利は fd ごと、向きは端ごとに決まる）
- 書き込みの不可分性（POSIX の `PIPE_BUF`）は保証しない。全部書くまで繰り返すかは ABI 層が決める（ADR 0058 と同じ）
- p1 の `fd_fdstat_get` などでの種類は、ほかのストリームと同じ `UNKNOWN`（ADR 0070）

## 規模

- バッファは `ByteStream` のとおり、最初の書き込みで小さく確保し、空になったら手放す。待っているだけのパイプはバッファを持たない
- パイプの数は fd の上限（プロセスあたり 256）で抑えられる。中身は RAM の勘定（`MemoryAccount`）に入れない（TTY のバッファと同じ。RAM の値が決まったら #251 で見直す）

## 決めないこと

- プログラム（WASM）からパイプを作る口（`kibi:*` の WIT、p1 の import、p2/p3 の stream との対応）: #75
- 保存のバイト形式: #81・#82
- バッファの大きさの確定: #251
