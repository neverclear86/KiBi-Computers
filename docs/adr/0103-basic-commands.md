# 0103: 標準 OS の基本コマンド

- 状態: 採用
- Issue: #103（task）。前提: ADR 0098（標準 OS のビルドと `kibi` ライブラリ）、0101（シェル）、0070・0071（WASI p1 の fd・path）、0074（`kibi:process`）
- 番号は Issue 番号にそろえている

## 決めたこと（要約）

- `/bin` に入れたコマンド: `cat` `clear` `cp` `du` `grep` `head` `kill` `ls` `mkdir` `mv` `pwd` `rm` `rmdir` `tail` `touch` `wc`（ほかに #98 の `echo` `true` `false`）
- #475 で足したもの: `sleep` `env` `printenv` `date` `seq` `yes` `sort` `uniq` `tee` `xargs` `basename` `dirname` `which`（下の「#475 で足したコマンド」）
- `cd` は外のコマンドにしない（子が cwd を変えても親のシェルに効かない）。シェルの組み込み（ADR 0101）を使う。`pwd`・`echo` は組み込みと外の両方がある
- 既存のシステムコールだけで作れないものは、この Issue から分けた（下の「残したもの」）。新しいシステムコール・保存形式・公開 API は足していない
- コマンドが共通に使うものは `kibi` ライブラリに足した: `cli`（オプション・知らせ・まとめて書く出力・行の読み方・パス）、`tree`（木を写す・消す）、`fs.lstat`、`fs.touchTimes`
  （import は既存の `path_filestat_get`（たどらない）・`path_filestat_set_times` で、ABI は ADR 0070・0071 のまま）

## 共通の約束

- オプションは短いものだけ（`-a -l`・`-al`・`-n 5`・`-n5`、`--` で終わり）。長いオプション（`--help` など）はない
- 知らせは `コマンド: 対象: 説明` を標準エラー出力に（説明は errno の strerror 相当。`kibi.errno.describe`）
- 終了コード: 成功 0、どれかの対象で失敗 1、使い方の誤り 2（`grep` は「合わない」が 1、エラーが 2）
- 標準出力は 4 KiB ずつまとめて書く（`cli.stdout`）。読み手が閉じたパイプ（`ls | head`）では、知らせずに終わる
- 領域は静的に置く（ADR 0098 と同じ。触るまで RAM に数えない）

## コマンドごと

| コマンド | オプション | 細かいところ |
| --- | --- | --- |
| `ls` | `-a -l -1 -F` | 名前のバイト順。TTY には画面の幅で段に並べる（上から下）。`-l` は `種類 大きさ 時刻 名前`（時刻は UTC の `YYYY-MM-DD HH:MM`。持ち主・権限はまだない #110）。1 ディレクトリ 2,048 項目・名前の合計 64 KiB まで |
| `cat` | `-u`（受け付けるだけ） | `-` は標準入力 |
| `cp` | `-r -R`（`-f` は受け付けるだけ） | 先がディレクトリならその中へ。自分の中へは写さない。中のシンボリックリンクは写さない（作る口を使っていない） |
| `mv` | （`-f` は受け付けるだけ） | `rename`。`XDEV`（別のファイルシステム）なら中身ごと写してから元を消す |
| `rm` | `-r -R -f` | `.`・`..`・`/` は断る。木を消すときは、1 つ消すたびにディレクトリを頭から読み直す（消しながら読む位置がずれないように） |
| `mkdir` | `-p` | |
| `rmdir` | `-p` | 書いたパスの上へ順に |
| `touch` | `-c` | 時刻を今にする（`path_filestat_set_times` の NOW）。なければ空のファイルを作る |
| `pwd` | `-L -P`（受け付けるだけ） | `fs.cwd()`（`PWD`） |
| `head` | `-n N`・`-N` | 2 つ以上なら `==> 名前 <==`（開けなかったファイルには書かない。`tail` も同じ） |
| `tail` | `-n N`・`-n +N`・`-N` | 普通のファイルは後ろから読む。パイプは最後の 64 KiB を覚えて読み通す。`-f` はない（変更を待つ口がない） |
| `grep` | `-E -F -G -c -H -h -i -l -n -q -s -v -x -e` | 正規表現は BRE・ERE のよく使う部分（`.` `[...]` `[:name:]` `*` `^` `$`、ERE の `+ ?`、BRE の `\+ \?`）。組・選択・回数・後方参照は未対応と知らせて 2。照合は後ろに戻る素朴な方式。1 行 64 KiB まで |
| `wc` | `-l -w -c` | 数は合計の桁にそろえる（数 1 つだけなら そろえない）。2 つ以上なら `total` |
| `du` | `-a -s -b -k` | ファイルの大きさの合計（KiB は切り上げ）。区画の数ではない |
| `kill` | `-s SIG`・`-SIG`・`-l` | シグナルはカーネルの 4 つ（INT 2・QUIT 3・KILL 9・TERM 15）。名前は大小・`SIG` の有無を問わない。知らないシグナルは使い方の誤り（2） |
| `clear` | | `ESC [H ESC [2J` |

### #475 で足したコマンド

| コマンド | オプション | 細かいところ |
| --- | --- | --- |
| `sleep` | | 秒（小数可）、後ろに `s` `m` `h` `d`。2 つ以上は合計。`time.sleep`（`poll_oneoff` の単調時計。待機点） |
| `env` | `-i`（`-`）`-u 名前` | `名前=値` を足してコマンドを動かす。なければ環境変数を書く。コマンドは変えた後の `PATH` から探す。カーネルは cwd から `PWD` を足すので、`env -i` でも `PWD` は残る |
| `printenv` | | 名前がなければ全部。なかった名前があれば 1 |
| `date` | `-u`（受け付けるだけ） | いつも UTC。既定は `%a %b %e %H:%M:%S UTC %Y`。`+書式` は strftime のよく使う部分。日時を変える口はない（1） |
| `seq` | `-w -s` | 10 進の小数（指数なし）。桁は最初と増分の多い方（最大 9 桁）。`-` の次が英字でなければ負の数 |
| `yes` | | 8 KiB ずつまとめて書く。書けなくなったら 0 で終わる |
| `sort` | `-b -f -n -r -u -k N[,M] -t C -o F` | 入力は全部メモリに（4 MiB・262,144 行まで）。読むたびに `memory.commit` で数え、足りなければ `out of memory` で 1（RAM の上限でトラップしない）。安定な併合ソート、鍵が同じなら行全体のバイト順（`-u` を除く）。`-t` がないときの欄は前の空白を含めない |
| `uniq` | `-c -d -u -i` | `[入力 [出力]]`。1 行 64 KiB まで |
| `tee` | `-a -i` | 標準出力が書けなくなっても、ファイルには書き続ける |
| `xargs` | `-0 -n -I -r -t` | 既定のコマンドは `echo`。1 回に 32 KiB・255 個まで。子の標準入力は閉じる。終了コードは POSIX（123・124・125・126・127） |
| `basename` | `-a -s` | |
| `dirname` | | |
| `which` | `-a` | `PATH` の普通のファイルだけ（組み込み・関数は `command -v`） |

コマンドを動かすもの（`env`・`xargs`）は `cli.run` を使う: WASM でない（`NOEXEC`）なら `/bin/sh` のスクリプトとして動かし、自分が TTY の前景なら待つ間は子を前景にする（Ctrl+C が子に届く）。TTY は標準入力・標準エラー・標準出力の順に最初に TTY だったものを見る（`seq 3 | xargs sleep 9` のように標準入力がパイプでも前景を渡す。#482）。前景にした子が Ctrl+C・Ctrl+\ で止まったら、自分も同じシグナルで止まる（Unix で同じプロセスグループにいるのと同じ。シェルはこれを見てパイプラインの残りも止める）。終了コードの写し方はシェルと同じ（`cli.exitCode`）。日時の計算は `time.civil` にまとめ、`ls -l` も使う。

木をたどるもの（`cp -r`・`rm -r`・`mv`・`du`）は深さ 32 まで（超えたら `LOOP`）。中のシンボリックリンクはたどらない。

## 残したもの（#103 から分けた）

| コマンド | 足りないもの |
| --- | --- |
| `ps` | プロセスの一覧を得るシステムコール（#452。`list-processes` は ADR 0452 で足した。Zig の `cabi_realloc` の export と表示は #454） |
| `df` | ファイルシステムの容量・空きを得るシステムコール（#453。`list-mounts` の `usage` は ADR 0453 で足した。表示は #454） |
| `mount`・`umount` | マウントの一覧（#453）と、マウント・アンマウントのシステムコール（#56。`mount`・`unmount` は ADR 0056、`list-mounts`・`list-disks` は ADR 0453 で足した。コマンドは #454） |
| `reboot`・`shutdown` | 停止・再起動のシステムコール（#306） |

どれもシステムコールの ABI を決める必要があり、人の判断の対象（AGENTS.md）なので、システムコールの Issue が閉じてから #454 でコマンドを足す。

## 確かめ方

`core` の `BasicCommandsTest`（`date` は時計を固定したマシンで）: 書けるメモリの FS にイメージの `/bin` を写し、`/mnt` に別の FS をつないで、シェルのスクリプトから各コマンドを動かす（出力と終了コード）。
