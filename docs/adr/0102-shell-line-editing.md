# 0102: シェルの行編集・補完・履歴

- 状態: 採用
- Issue: #102（task）。前提: ADR 0060（TTY）、0061（端末の解釈）、0101（`/bin/sh`）、0427（`kibi:io/tty`）
- 番号は Issue 番号にそろえている

## 決めたこと（要約）

- ソースは `os/bin/sh/edit.zig`（行の編集と表示）・`complete.zig`（補完の候補）・`history.zig`（履歴）。`exec.Reader` は、会話的で標準入力と標準エラー出力が TTY のときだけ `edit.readLine` で 1 行ずつ読む
- 新しいシステムコール・公開 API・MOD のセーブデータの形は足していない。使うのは `kibi:io/tty` の `get-mode`・`set-mode`・`get-size` だけ
- 履歴のファイルは、ユーザーランドのただのテキストファイル（1 行に 1 項目）

## TTY のモード

- 行を読む間だけ、モードを「出力の LF → CR LF だけ残し、ほかは全部オフ」にする（canonical・エコー・シグナル・CR → LF なし）。確定・取り消し・入力の終わりで元のモードに戻すので、子のプログラムは canonical の TTY を見る
- 読む前のモードが canonical でなければ（子が raw のまま終わった）、戻すのは既定（cooked）
- 1 バイトずつ読む。確定した行の後ろの入力（先打ち・貼り付けた複数の行）を TTY に残し、次に動くプログラム（`cat` など）や次の行の編集が読めるようにするため
- Ctrl+C はシグナルにならず、ただのバイトとして届く（シェルは前からシグナルを無視している）

## 表示

- 行は、プロンプトの始まり（行の頭）からの相対で、折り返した複数の行として描き直す（`CSI n A` で始まりの行へ、`CR`・`CSI J`、プロンプトと行、`CSI n A`・`CR`・`CSI n C` でカーソルへ）
- 位置は、端末の解釈（ADR 0061）と同じ規則で数える: 右端に書いたら折り返しの保留、全角の文字は右端の 1 セルに入らなければ次の行へ、全角の範囲は `CharWidth` と同じ、結合文字などの主な範囲は幅 0。行の中の制御文字は `^X` で 2 セル
- UTF-8 の読み方と文字の幅は `kibi.text`（ADR 0105。#610）。不正な UTF-8 は 1 バイトごとに、C1 の制御文字（U+0080〜U+009F。端末が読み捨てる）は 1 文字を U+FFFD（1 セル）にして送り、原文のバイトは送らない（端末の側で別の文字に読まれ、数えた位置とずれるため）。前に文字のない幅のない文字は、端末と同じく幅 0 のまま送る
- 行の末尾で折り返しの保留になったら、改行を書いてカーソルを次の行の頭に出しておく
- 行の末尾に足して折り返さないときは、その文字だけを書く（描き直さない。出力と画面の同期を小さくする）
- プロンプトの前に、画面の幅だけ空白を書いて `CR`・`CSI K` する。前の出力が改行で終わっていなくても（`printf abc`）、それを消さずに次の行の頭から始まる
- プロンプト（`PS1`・`PS2` を展開したもの）の中のエスケープシーケンスは幅 0 と見て、そのまま送る。改行・CR・タブも数える。文字は行と同じく読み、不正な UTF-8 と C1 は U+FFFD にして送る（書く処理と数える処理は同じ関数）
- 画面の大きさは描き直すたびに `get-size` で読む（`tty-resize` のイベントは待たない）

## キー

| キー | 動き |
| --- | --- |
| Enter（CR・LF） | 確定 |
| ←・→、Ctrl+B・Ctrl+F | 1 文字（UTF-8 の 1 文字）動く |
| Ctrl+←・Ctrl+→、Alt+B・Alt+F | 語（英数字と 0x80 以上のバイトの並び）の頭・終わりへ |
| Home・End、Ctrl+A・Ctrl+E | 行の頭・後ろへ |
| Backspace（DEL・BS）、Delete | 前・カーソルの文字を消す |
| Ctrl+D | 空の行なら入力の終わり（シェルが終わる）。ほかはカーソルの文字を消す |
| Ctrl+K・Ctrl+U | カーソルから後ろ・前を消す |
| Ctrl+W | 前の、空白で区切った語を消す |
| Alt+D・Alt+Backspace | 後ろ・前の語を消す |
| Ctrl+Y | 最後に消したもの（Ctrl+K・U・W・Alt+D・Alt+Backspace）を入れる |
| Ctrl+T | カーソルの前後の文字を入れ替える |
| ↑・↓、Ctrl+P・Ctrl+N | 履歴 |
| Tab | 補完 |
| Ctrl+C | 行を捨てて `^C` と改行を書く。続きの行（`PS2`）の途中なら、読みかけのコマンド全体を捨てる。`$?` は 130 |
| Ctrl+L | 画面を消して、行を一番上に描き直す |

- 読むシーケンス: `CSI` … 終わりのバイト（`A`〜`D`・`H`・`F`・`1~`・`7~`・`4~`・`8~`・`3~`、修飾 `;5`・`;3`）、`ESC O` ＋ 1 バイト。ほかは読み捨てる。ほかの制御文字は無視する
- 行は 4096 バイトまで（入力の領域の残りがそれより小さければ、そこまで）。入らなければ BEL（入らなかった最初の 1 回だけ）
- 上限を超えて入力の一部を捨てた行は、Enter で実行しない（#665）。切れた行を実行すると、リダイレクトやパイプの先が消えて意図と違う動作になるため
  - `sh: line too long` を出し、`$?` は 2（`command too long` と同じ）。履歴にもファイルにも残さない
  - 続きの行（`PS2`）なら、Ctrl+C と同じく読みかけのコマンド全体を捨てる（前の行と次の行がつながって別のコマンドにならないよう）
  - 捨てたかどうかは、長さではなく印で見る。Backspace で上限より短くしても、捨てた中身は戻らないので実行しない。行を全部消す（Ctrl+U など）と印は外れ、打ち直した行は実行する。履歴を呼び戻すと印は外れ、↓で編集中の行に戻ると印も戻る
  - UTF-8 の 1 文字は、丸ごと入らなければ先頭のバイトも入れない（半端な文字を残さない）
  - 行の後ろの入力（貼り付けの 2 行目以降・先打ち）は TTY に残したまま読み、次の行として扱う（1 バイトずつ読む方針どおり。bash と同じ）
- 履歴の呼び戻しで項目が入らなければ（続きの行で入力の領域の残りが少ないとき）、BEL で行はそのまま（切って入れない）。補完で入れる文字も、全部入るか何も入らないか

## 履歴

- 確定した行（改行を含まない）を 1 項目として残す。空白だけの行・直前と同じ行・4096 バイトを超える行は残さない。続きの行（`PS2`）も 1 行ずつ残す
- ↑で 1 つ古い項目、↓で新しい項目。一番新しい項目の次は、呼び戻す前に編集していた行に戻る。呼び戻した行を直して確定すると、新しい項目になる（元の項目は変わらない）
- 残す数は `HISTSIZE`（既定 500、上限 1,000。仮の値）。文字の合計は 64 KiB まで。超えたら古いものから捨てる
- ファイルは `HISTFILE`（空ならファイルを使わない）、なければ `$HOME/.sh_history`。確定するたびに後ろに足す（電源が切れても残る）。会話的なシェルの起動時に読み、残す数より多く書いてあれば、残す分だけで書き直す。書けなければ黙って続ける
- 組み込み `history` は番号つきで並べる。`history -c` はメモリの履歴だけを消す。`history` はパイプラインの段・コマンド置換でもシェルの中で動かす（子のシェルは履歴を持たないため）

## 補完

- Tab で、カーソルの前の語を補う。語は、引用の外の空白・`;`・`|`・`&`・`<`・`>`・`(`・`)` で区切り、引用と `\` を外して比べる
- 候補:
  - `$` で始まり `/` がない: 値のある変数の名前（`$NAME`）
  - コマンドの位置（行の頭、`;`・`|`・`&`・`(` の後、`then`・`do`・`if` などの後）で `/` がない: 組み込み・関数・`PATH` のディレクトリのファイル
  - ほか: パス。最後の `/` までをディレクトリ（`~/` は `HOME`）として読み、残りで始まる名前。`.` で始まる名前は、`.` を打ったときだけ
- 候補が 1 つなら、残りを入れ、ディレクトリなら `/`、ほかは（開いている引用を閉じて）空白を足す。いくつかあれば共通の頭まで入れる。それ以上入れられなければ BEL、続けてもう一度 Tab で候補を段に並べて書き、行を描き直す
- 入れる文字は、引用の外なら空白・`$`・`*` などの前に `\` を付け、`"` の中なら `"`・`\`・`$`・`` ` `` だけに付ける
- 候補は 1,024 個・名前の合計 64 KiB まで（超えたら「省いた」と書く）

## 今の制限（必要になったら足す）

- 履歴の検索（Ctrl+R）、`!` の履歴展開、`fc` はない
- 行が画面の高さより長いと、描き直しが崩れる（端末は画面の上より上へ戻れない）
- 編集中に画面の大きさが変わると、次に描き直すまで表示がずれることがある（端末は折り返しを組み直さない）
- 結合文字は 1 文字として動く（カーソルは見た目では動かない）

## 追記（#87）: 保存から戻ったときの描き直し

- `readLine` の間だけ、`restored` だけを受け取るキューを開き、戻るときに閉じる（子が前に出ている間に古い合図を溜めない。fd 3 以降は子に渡らない）
- キーの境目（UTF-8 の続きや `ESC [` の途中でないとき）だけ、標準入力とキューを `poll_oneoff` で待つ。途中は今までどおり標準入力だけを読む
- `restored`（source `""`）か `dropped > 0` を受けたら、`refresh()` だけで行を描き直す（`\x1b[2J` で消したり `freshLine` を呼んだりしない。画面が空ならカーソルは左上で、上へ戻る CSI は上端で止まるので正しく描ける。画面が残っていても相対の描き直しなので崩れない）
- キューを開けなければ、標準入力だけを待つ。待ちや取り出しに失敗したら（ハンドルが不正なときだけ）、閉じずに手放して標準入力だけを待つ（不正なハンドルの drop はトラップするため。ADR 0087）
- 確かめ方: `core` の `StandardOsRestoreTest`（ADR 0087）
