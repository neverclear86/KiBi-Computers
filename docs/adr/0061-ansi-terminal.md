# 0061: ANSI エスケープシーケンスの解釈

- 状態: 採用
- Issue: #61（task）。前提: ADR 0060（TTY）、#135（画面バッファ）、ADR 0031（画面の同期）
- 後続: #65・#66（画面のデバイスとコンソールをつなぐ）、#139（カーソルの描画）、#82（保存の形）
- 対応範囲の仕様: `docs/terminal.md`

## 決めたこと（要約）

- コードは `core.display.terminal`。`AnsiTerminal`（解釈器）と `TerminalColors`（色の丸め）。どれも `internal`。公開 API・ABI・保存のバイト形式は足さない
- `AnsiTerminal` は、TTY の出力のバイト列（UTF-8）を受け取り、文字画面のバッファ（`TextBuffer`）に書く。バイト列はどこで切れていてもよい
- 範囲は VT100 のサブセットと、エディタ・シェルがよく使う xterm の拡張（256 色・RGB、代替画面 1049、ECH・ICH・SU・SD など）。知らないシーケンスは読み捨てる
- LF は「1行下へ」だけ（TTY が LF を CR LF にしている。ADR 0060）

## 解釈器

- VT500 系の状態機械（Paul Williams の解釈器）を簡略にした形。状態は GROUND・ESCAPE・ESCAPE_INTERMEDIATE・CSI_PARAM・CSI_IGNORE・OSC_STRING・STRING_IGNORE の7つ
- CSI のパラメーターは 16 個まで、1つは 65535 まで（超えた分は切り詰める）。`:` の区切りは SGR の 38・48 でだけ意味を持つ
- 制御文字はシーケンスの途中でもその場で効く。CAN・SUB は取り消し。OSC・DCS などの文字列は中身を持たずに読み捨てる（メモリを使わない）
- UTF-8 は自前で1バイトずつ解く（途中で切れた文字は次の `write` で続ける）。不正なバイト列・サロゲート・冗長な表現は U+FFFD

## 画面への書き方

- 同じ行・同じ色で続く文字は、まとめて `TextBuffer.write` 1回で書く（描画命令の記録を小さくするため）。制御文字・シーケンス・`write` の終わりで書き出す
- 全角の文字は、そのセルと右隣の空白の2セル（`CharWidth`・#139 の約束と同じ）
- 消去・スクロールで空いたセルは、反転を除いた今の背景色（xterm の bce と同じ）
- 右端に書いた後は「折り返しの保留」にし、次の文字を書くときに折り返す（DECAWM）

## 色

- 色の指定は `Int` 1つ（既定 −1、パレットの番号 0〜255、RGB は `0x1000000 | rgb`）で持ち、書くときの色（`0xRRGGBB`）は属性か色数が変わったときだけ求め直す
- 色数は `maxColors`（画面と GPU の低い方。呼ぶ側が渡す）。2 以下は単色、16〜255 は 16 色、256 は 256 色、それより多ければ RGB のまま
- 16 色・256 色への丸めは、重み付きの RGB の距離（2:4:3）でいちばん近い色。整数だけで計算する
- 単色は、背景を明るさ（BT.601）で白か黒にし、前景をその反対にする。黒の文字を黒の背景に書いても読めるようにするため。反転は効く
- 基本の 16 色は xterm の既定に近い値（仮の値）

## 代替画面

- 入るときに元の画面を `TextBuffer.copyOf()` で写し、出るときに書き戻す。写しを持つのは代替画面にいる間だけ（1,000台のほとんどは持たない）
- 書き戻しは同じ色が続くセルをまとめた `write` で行う。画面全体を書き換えるので、描画命令が多ければ同期は自動でキーフレームになる（ADR 0031）
- 47・1047・1049 のどれも、入ると空の画面になる。1049 だけカーソルを保存・復元する

## 大きさ

- バッファの大きさは外から変えてよい。`write` の始めに比べ、変わっていればスクロール領域を画面全体に戻し、カーソルを画面の中に入れる。代替画面にいれば、元の画面の写しも同じ大きさにする

## 保存（#82 への申し送り）

`AnsiTerminal` は番号・真偽・配列だけを持つ: カーソル（位置・表示・折り返しの保留）、スクロール領域、モード（自動折り返し・原点・挿入）、色の指定と属性、文字集合、タブ位置（既定なら null）、保存したカーソル2つ、代替画面の元の画面の写し、解釈の途中の状態（状態の番号・パラメーター・UTF-8 の途中の文字）。
書き出していない文字の並び（`run`）は `write` の終わりに必ず空になるので、保存しなくてよい。

## 接続（#65・#66 への申し送り）

- `MachineHost.onConsoleOutput` のバイト列を、画面ごとの `AnsiTerminal.write` に渡す。接続層から使うには `public` にするか、`core` の側で画面とコンソールをつなぐ
- 応答（DSR・DA）は `TerminalListener.reply` で返すので、`Machine.offerConsoleInput` に渡す
- BEL は `TerminalListener.bell`。`MachineHost.onBeep` とつなぐかは接続のタスクで決める
- カーソルの位置と表示は `cursorX`・`cursorY`・`cursorVisible`。描画（#139）と同期で使う
