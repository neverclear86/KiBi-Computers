# 端末（ANSI エスケープシーケンス）の対応範囲

KiBi Computers の画面は、コンソールの出力を VT100 互換のサブセットと、よく使う xterm の拡張として解釈する（#61）。
ここに書いていないシーケンスは、読み捨てる（画面には何も出ない）。

- 文字コードは UTF-8。不正なバイト列は U+FFFD（�）になる
- 端末の名前としては `TERM=xterm-256color` のサブセットにあたる。ただし色数は画面のティアで変わる（下の「色」）
- 座標は 1 から数える（`CSI 1;1 H` が左上）
- `n` は数のパラメーター。省略と 0 は、ことわりのない限り 1 として扱う

## 制御文字

| 文字 | 動き |
| --- | --- |
| BEL（0x07） | ビープ |
| BS（0x08） | 1 つ左へ（左端では動かない） |
| HT（0x09） | 次のタブ位置へ（既定は 8 桁ごと。なければ右端） |
| LF・VT・FF（0x0A〜0x0C） | 1 行下へ（スクロール領域の下端ならスクロール）。行の先頭へは戻らない（TTY が LF を CR LF にする） |
| CR（0x0D） | 行の先頭へ |
| SO・SI（0x0E・0x0F） | 文字集合 G1・G0 に切り替える |
| CAN・SUB（0x18・0x1A） | 途中のエスケープシーケンスを取り消す |
| ESC（0x1B） | エスケープシーケンスの始まり |
| DEL（0x7F）、C1（U+0080〜U+009F） | 無視する |

制御文字はエスケープシーケンスの途中に来ても、その場で効く。

## ESC で始まるもの

| シーケンス | 名前 | 動き |
| --- | --- | --- |
| `ESC 7` / `ESC 8` | DECSC / DECRC | カーソル（位置・色と属性・文字集合・原点モード）を保存する / 戻す |
| `ESC D` | IND | 1 行下へ（下端ならスクロール） |
| `ESC E` | NEL | 次の行の先頭へ |
| `ESC M` | RI | 1 行上へ（上端なら下へスクロール） |
| `ESC H` | HTS | 今の桁にタブ位置を置く |
| `ESC c` | RIS | 端末を最初の状態に戻す（画面を消し、代替画面から出る） |
| `ESC ( 0` / `ESC ( B` | SCS | G0 を DEC の線画文字 / ASCII にする |
| `ESC ) 0` / `ESC ) B` | SCS | G1 を DEC の線画文字 / ASCII にする |
| `ESC # 8` | DECALN | 画面を `E` で埋める |
| `ESC ]` … BEL か `ESC \` | OSC | 読み捨てる（ウィンドウのタイトルなど） |
| `ESC P`・`ESC X`・`ESC ^`・`ESC _` … `ESC \` | DCS・SOS・PM・APC | 読み捨てる |

DEC の線画文字は、`_`〜`~`（0x5F〜0x7E）を罫線などに置き換える（`q` → `─`、`x` → `│`、`l` → `┌` など。VT100 と同じ表）。

## CSI（`ESC [`）で始まるもの

### カーソル

| シーケンス | 名前 | 動き |
| --- | --- | --- |
| `CSI n A` / `B` | CUU / CUD | n 行上 / 下へ（スクロール領域の中にいれば、その端で止まる） |
| `CSI n C` / `D` | CUF / CUB | n 桁右 / 左へ |
| `CSI n E` / `F` | CNL / CPL | n 行下 / 上の先頭へ |
| `CSI n G`、`` CSI n ` `` | CHA / HPA | n 桁目へ |
| `CSI n d` | VPA | n 行目へ |
| `CSI r ; c H`、`CSI r ; c f` | CUP / HVP | r 行 c 桁目へ（原点モードではスクロール領域の上端から数え、領域の外へは出ない） |
| `CSI n I` / `CSI n Z` | CHT / CBT | n 個先 / 前のタブ位置へ |
| `CSI s` / `CSI u` | SCOSC / SCORC | `ESC 7` / `ESC 8` と同じ |

### 消去と編集

消した場所は、今の背景色（反転を除く）の空白になる。

| シーケンス | 名前 | 動き |
| --- | --- | --- |
| `CSI 0 J` / `1 J` / `2 J`・`3 J` | ED | カーソルから画面の終わりまで / 画面の始まりからカーソルまで / 画面全体を消す |
| `CSI 0 K` / `1 K` / `2 K` | EL | カーソルから行末まで / 行頭からカーソルまで / 行全体を消す |
| `CSI n X` | ECH | カーソルから n 文字を消す（カーソルは動かない） |
| `CSI n @` / `CSI n P` | ICH / DCH | カーソルの位置に n 文字の空白を入れる / n 文字を消して左に詰める |
| `CSI n L` / `CSI n M` | IL / DL | カーソルの行に n 行を入れる / n 行を消す（スクロール領域の中だけ。カーソルは行の先頭へ） |
| `CSI n S` / `CSI n T` | SU / SD | スクロール領域を n 行上 / 下へスクロールする |
| `CSI t ; b r` | DECSTBM | スクロール領域を t〜b 行目にする（省略で画面全体。t < b でなければ無視）。カーソルは原点へ |
| `CSI 0 g` / `CSI 3 g` | TBC | 今の桁の / すべてのタブ位置を消す |

### モード

| シーケンス | 名前 | 動き |
| --- | --- | --- |
| `CSI 4 h` / `l` | IRM | 挿入モード（書くと右の文字を押し出す） / 上書きモード（既定） |
| `CSI ? 6 h` / `l` | DECOM | 原点モード（位置をスクロール領域から数える） / 画面から数える（既定） |
| `CSI ? 7 h` / `l` | DECAWM | 右端で折り返す（既定） / 折り返さずに右端に上書きする |
| `CSI ? 25 h` / `l` | DECTCEM | カーソルを表示する（既定） / 隠す |
| `CSI ? 47 h`、`CSI ? 1047 h` | | 代替画面に入る（空の画面になる）。`l` で元の画面に戻る |
| `CSI ? 1048 h` / `l` | | カーソルを保存する / 戻す |
| `CSI ? 1049 h` / `l` | | カーソルを保存して代替画面に入る / 元の画面に戻ってカーソルを戻す（エディタはこれを使う） |
| `CSI ! p` | DECSTR | 端末の設定（モード・スクロール領域・属性・文字集合）を既定に戻す。画面は消さない |

代替画面の中身は、出るときに捨てる（次に入ると空の画面）。代替画面に入っている間に画面の大きさが変わっても、元の画面は新しい大きさで残る。

### 色と属性（SGR、`CSI … m`）

| パラメーター | 動き |
| --- | --- |
| 0（省略も） | すべての属性を戻す |
| 1 / 22 | 太字（前景が基本の 0〜7 番なら明るい 8〜15 番にする） / 戻す |
| 7 / 27 | 反転（前景と背景を入れ替える） / 戻す |
| 8 / 28 | 隠す（前景を背景と同じにする） / 戻す |
| 30〜37 / 40〜47 | 前景 / 背景を基本の色（0〜7 番）にする |
| 90〜97 / 100〜107 | 前景 / 背景を明るい色（8〜15 番）にする |
| 39 / 49 | 前景 / 背景を既定の色にする |
| `38;5;n` / `48;5;n` | 前景 / 背景を 256 色のパレットの n 番にする（`38:5:n` も可） |
| `38;2;r;g;b` / `48;2;r;g;b` | 前景 / 背景を RGB にする（`38:2::r:g:b`・`38:2:r:g:b` も可） |

薄い（2）・斜体（3）・下線（4）・点滅（5・6）・取り消し線（9）と、その解除は受け付けるが、画面には出ない。

### 応答

応答はコンソールの入力として、プログラムが標準入力から読む。

| シーケンス | 名前 | 応答 |
| --- | --- | --- |
| `CSI 5 n` | DSR | `CSI 0 n`（正常） |
| `CSI 6 n` | CPR | `CSI r ; c R`（カーソルの位置。原点モードではスクロール領域から数える） |
| `CSI c`、`CSI 0 c` | DA | `CSI ? 1 ; 2 c`（VT100 と同じ） |
| `CSI > c` | DA2 | `CSI > 0 ; 0 ; 0 c` |

## 色

画面に出せる色の数は、画面のティアと GPU カードのティアの低い方で決まる。指定した色は、その色数に丸める。

| 色数 | 丸め方 |
| --- | --- |
| 2（単色） | 背景を明るさで白か黒にし、前景をその反対にする（文字がいつも読める）。反転・隠しは効く |
| 16 | 基本の 16 色はそのまま。256 色の 16 番以降と RGB は、いちばん近い基本の色にする |
| 256 | パレットはそのまま。RGB は、いちばん近いパレットの 16〜255 番の色にする |

基本の 16 色（仮の値）:

| 番号 | 色 | 番号 | 色 |
| --- | --- | --- | --- |
| 0 | `#000000` 黒 | 8 | `#7F7F7F` 明るい黒（灰色） |
| 1 | `#CD0000` 赤 | 9 | `#FF0000` 明るい赤 |
| 2 | `#00CD00` 緑 | 10 | `#00FF00` 明るい緑 |
| 3 | `#CDCD00` 黄 | 11 | `#FFFF00` 明るい黄 |
| 4 | `#0000EE` 青 | 12 | `#5C5CFF` 明るい青 |
| 5 | `#CD00CD` マゼンタ | 13 | `#FF00FF` 明るいマゼンタ |
| 6 | `#00CDCD` シアン | 14 | `#00FFFF` 明るいシアン |
| 7 | `#E5E5E5` 白 | 15 | `#FFFFFF` 明るい白 |

既定の前景色は `#FFFFFF`、背景色は `#000000`。256 色のパレットの 16〜231 番は 6x6x6 の色の立方体、232〜255 番は 24 段の灰色（xterm と同じ）。

## 文字

- 全角の文字（漢字・かななど）は 2 セルを使う。右端の 1 セルに入らないときは、そのセルを空けて次の行に書く（折り返さないモードでは、右から 2 セル目に書く）
- 全角の文字の右半分に別の文字を書くと、左半分の全角の文字は消える
- 結合文字（アクセント記号など）と書式文字（ゼロ幅のもの）は読み捨てる
- 右端に書いた後は、次の文字を書くときに折り返す（右端でちょうど CR LF しても、空の行はできない）
